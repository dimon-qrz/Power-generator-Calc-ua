Power-generator-Calc UA is a modern web application designed to help users calculate and select the optimal generator power during blackouts and emergency power outages caused by attacks on energy infrastructure.

# Power-generator-Calc-ua
 Power-generator-Calc UA — це зручний та сучасний вебдодаток, створений для допомоги у виборі оптимальної потужності генератора під час аварійних відключень електроенергії. Калькулятор розроблений з урахуванням реальних потреб українців в умовах блекаутів, спричинених атаками на енергетичну інфраструктуру.
